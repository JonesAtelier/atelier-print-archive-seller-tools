# Atelier Print Archive Seller Tools

Public application information and policies for the private Etsy Seller App
used by Atelier Print Archive.

## Publish with GitHub Pages

1. Create a new public GitHub repository.
2. Upload this project and commit it to the `main` branch.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **GitHub Actions**.
5. Open the **Actions** tab and allow the included “Deploy GitHub Pages”
   workflow to finish.

The workflow automatically handles both a normal project-page URL
(`username.github.io/repository`) and a user-page repository
(`username.github.io`).

## Etsy URLs

After GitHub Pages publishes the site, use:

- Application website: the homepage URL
- Privacy policy: `/privacy/`
- Terms of use: `/terms/`

No Etsy API keys, OAuth tokens, or shop data belong in this repository.
